## 🆕 Universal Coverage via `guesty raw` (added 2026-05-10)

The 11 named commands above cover the most common workflows. For the other **300+ endpoints** Guesty exposes — including marketing/translations, accounting, complexes, spaces, taxes, payment providers, channel commissions, smart locks, group reservations, the v3 reservations API, rate plans, and more — use `guesty raw`:

```bash
# Discover what's in the API
guesty raw --list                          # 60 categories, endpoint counts
guesty raw --list --category calendar      # all calendar endpoints
guesty raw --search "rate-strateg"         # fuzzy search by path/title

# Make any call
guesty raw GET  /v1/accounts/me
guesty raw GET  /v1/listings --params '{"limit":5,"fields":"_id title"}'
guesty raw PUT  /v1/availability-pricing/api/calendar/listings/<id> \
  --data '{"startDate":"2026-06-01","endDate":"2026-06-07","price":389,"minNights":7}'
guesty raw POST /v1/webhooks --data '{"event":"reservation.new","url":"https://..."}'
guesty raw DELETE /v1/listings/<id>

# Pipe-friendly: --output for binary/CSV, --accept for content-type
guesty raw POST /v1/reservations.csv --accept text/csv --output reservations.csv

# All standard guesty flags work (auth, rate limiting, --json, --access-token, etc.)
```

### Read-only-by-design endpoints to know about

- **Rate strategies** (`/v1/rm-rate-strategies-open-api/rate-strategies`) — only 2 GET endpoints in the Open API. To mutate rate-strategy behavior, write equivalent date-level overrides via the calendar endpoint instead:

  ```bash
  guesty raw PUT /v1/availability-pricing/api/calendar/listings/<id> \
    --data '{"startDate":"2026-12-20","endDate":"2026-12-27","price":650,"minNights":7,"cta":true,"ctd":true}'
  ```

  `cta` (closed-to-arrival) and `ctd` (closed-to-departure) per date give you Saturday-to-Saturday equivalent without touching the rate strategy abstraction.

### Refreshing the spec

The spec was generated by scraping Guesty's public docs sitemap. Re-run periodically as Guesty adds endpoints:

```bash
python scripts/scrape_api_docs.py     # ~55s, 319 endpoint docs into docs/api-reference/
python scripts/refresh_api_spec.py    # compiles them into api-spec.json
```

The scraper fetches the slug list **dynamically** from `https://open-api-docs.guesty.com/sitemap.xml` so it stays current without hand-editing.

## For AI Agents

### Optimal Patterns

**Read Operations (Local DB):**
```bash
guesty reservations --today --json           # Fast, no API call
guesty occupancy --month 2024-01 --json      # Local analytics
guesty search "guest name"                   # FTS5 search
```

**Write Operations (Always --dry-run first):**
```bash
guesty calendar block-all --from DATE --to DATE --listings "id1,id2" --dry-run
guesty task create --title "Fix AC" --listing "Property" --dry-run
guesty reservation update CODE --status canceled --dry-run
```

**Sync Operations (Incremental preferred):**
```bash
guesty sync --incremental                    # Only changes since last sync
guesty sync reservations --incremental       # Specific table
guesty sync                                  # Full sync when needed
```
